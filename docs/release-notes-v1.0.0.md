# Release Notes – Network Speed Monitor v1.0.0

**Date:** 2026-06-07

## New Features
- VPN‑aware polling: bypasses VPN tunnels to measure true physical speed
- Randomized intervals (3-5 min) to avoid alignment with network events
- Daily graph with minute resolution
- 7-day stacked trend view
- Worst‑time analysis (15-min windows)
- Windows service support for 24/7 operation
- Portable single EXE, runs from USB
